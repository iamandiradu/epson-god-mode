You're helping me finish the macOS version of **Epson God Mode**, an open-source Epson printer maintenance tool
(waste ink pad counter read/reset, status and ink levels, cleaning, nozzle check, EEPROM backup/restore,
adjustment guidance). It's Python 3.10+ with a PySide6 GUI (`egm gui`) and a CLI (`egm ...`), licensed
AGPL-3.0. It already works on Windows against a real Epson L3111 over USB. Nobody has run it on a Mac yet.

**Get the code:** `git clone https://github.com/iamandiradu/epson-god-mode.git && cd epson-god-mode`, then read `README.md`,
`docs/SIGNING.md` and `docs/HARDWARE_TEST.md`.

**How it fits together (so you don't have to rediscover it):**
- `egm/modeldb.py` + `egm/data/models.json` hold the per-model EEPROM data (generated by `tools/build_models.py`).
- `egm/transport/usb.py` talks USB through the `epson-usb` package (IEEE 1284.4 "D4", EPSON-CTRL channel).
  On macOS that uses libusb via ctypes; `libusb-package` provides the library and `EPSON_USB_LIBUSB`
  can point at it. The link auto-reconnects, sends a D4 Exit before releasing the port, and `print_raw()`
  writes print jobs straight down the USB pipe (no print queue).
- `egm/printjobs.py` builds the jobs. Nozzle check and head cleaning are byte-identical to gutenprint's
  `escputil`, and each job must end with a form feed (`FF ESC 00 ESC 00`), or the printer stalls mid-page.
- `egm/operations.py` (`PrinterSession`) holds the safety rules: backup before every write, read-back
  verification, dry-run mode, cleaning confirmed by the waste counter rising.
- `sim:<MODEL>` (e.g. `-d sim:L3111`) is a full simulated printer. Use it before touching hardware.

**Tasks, in order:**
1. Create a venv, `pip install -e ".[patterns,macos,dev]"`, run `pytest -q` (36 tests should pass), and run
   `python -m egm -d sim:L3111 info` plus `python -m egm gui` against the simulator. Fix anything Mac-specific.
2. Build with `./build_mac.command` (or `bash build_mac.command`). It should produce
   `dist/Epson God Mode.app` and `dist/EpsonGodMode-macos-<arch>.dmg`, ad-hoc signed. Check that the app
   launches from Finder, that the bundled libusb is found (see `packaging/gui_entry.py`), and that the
   `egm` binary inside the bundle runs. Fix the PyInstaller spec (`packaging/egm.spec`) if needed.
3. If I have connected a printer over USB, test **read-only first**: `egm discover`, `egm info`,
   `egm counters`, `egm backup --full`. If libusb can't claim the printer interface (macOS may hold it for
   printing, or report access errors), investigate and fix it in `egm/transport/usb.py`. Don't just tell me to
   use `sudo`. Then test a nozzle check (`egm print nozzle-check`, which goes direct over USB) and one
   Normal cleaning from the GUI.
4. Report what worked, what you changed and why, and anything still broken.

**Rules:**
- **Never write to the printer's EEPROM or reset waste counters** (`reset-waste`, `write`, `restore`, Adjustments
  writes) without asking me first in the chat. Dry runs (`--dry-run`) are fine.
- Don't run more than one cleaning in a row: each one fills the waste ink pads.
- Never commit or push the `source/` folder, any `.pfx/.p12`, or `signing.env.*` files (they're git-ignored; keep it that way).
- Work on a branch (`mac-support`), commit with clear messages, and ask me before pushing.
- Code signing and notarization need my Apple Developer account. Don't set them up unless I ask; the
  ad-hoc build is the goal for now.
